## 剪辑流程

1. 点击“导入”选择视频、音频或图片，或将文件拖进窗口。
2. 点击素材卡片添加到时间线，或将它拖入四条画面轨或四条音频轨中的目标位置。拖动片段调整时间或轨道，拖动两端裁剪；松手提交，Esc 或窗口失焦取消，落点冲突会明确拒绝。
3. 播放头移到片段内部，选中片段按 `B` 或点击剪刀分割。右侧可以调整入点、时长、倍速、画面轨道和缩放/位置/旋转/翻转/透明度；“调节”页修改基础调色。
4. 在“文本”页添加或导入 SRT 字幕，修改文字、时间、字号、颜色、位置和描边；在“音频”页添加配乐，片段音频页可分离原声、设置分贝音量与关键帧、静音/独听、左右平衡、高低通、回声及四种形状的淡入淡出，并生成整个工程的保调 WAV 预听。桌面播放器下方可启动实时音频并录制最多30秒实际混音；源/速度修改会重新准备，音效和音量键会更新播放处理。无桌面桥的浏览器模式明确不提供实时音频。修改工程后旧离线预听会明确标记，需手动重新生成。
   “画面 → 位置大小”通过菱形添加变换关键帧，从列表选择并编辑缓动；“画面 → 变速”可选常规、分段恒速或平滑曲线，拖节点或精确输入源位置和倍速。“动画”页设置渐显/渐隐、四方向滑动、缩放、旋转、弹性缩放、缩放渐显或旋转渐显及缓动；“蒙版”页设置圆形或矩形及羽化/反转；“转场”将叠化、四方向擦除、淡黑、圆形展开/收拢、左右推进、左右滑入或淡白添加到同轨紧邻下一段的接点。
5. 工程自动保存，也可以手动保存。通过“打开工程”恢复已存工程、下载或打开 `.weijian.json` 文件。
6. 点击“导出”，选择分辨率、帧率和画质，等待真实合成完成后下载或预览 MP4。桌面版下载使用 macOS 保存对话框，默认位置是 `~/Movies/微剪导出/`，也可以选择其他文件夹。

### 工程和素材保存在哪里

桌面资料库固定保存在 `~/Library/Application Support/微剪/Library/`，与应用程序和源码目录分开。导入会在资料库创建素材副本；更换 `.app` 不会改写资料库。工程保存在其 `projects/`，后台合成的成片保存在其 `exports/`；下载视频会另存一份到所选位置。应用菜单“文件 → 显示本机资料库”和“文件 → 显示视频导出文件夹”可以打开相应目录。

工程 JSON 引用资料库的媒体 ID，不包含视频或音频本体。单独复制 `.weijian.json` 不能代替完整资料库备份；迁移或备份时应保留整个 `Library/`。

### 导入旧网页版工程

在桌面应用菜单选择“文件 → 导入旧网页版资料库…”，选中旧项目的完整 `data/` 文件夹，然后选择“导入并重启”。应用先保存当前工程，再复制并合并旧素材和工程；原网页版文件夹保持不变。提交导入前，会将当前桌面资料库备份为同级的 `Library.backup-<时间戳>`。内容冲突或无效记录会中止导入。该入口导入的是微剪旧网页版资料库。剪映草稿导入已加入 [优先需求](JIANYING-DRAFT-COMPATIBILITY-REQUIREMENTS.md)，尚未实现，不能用此菜单导入剪映草稿。

## 网页开发模式（可选）

桌面应用的日常使用不需要以下步骤。开发网页版时可运行：

```sh
npm ci
npm run dev
```

需要 Node.js 22.19+；FFmpeg/FFprobe 通过项目 npm 依赖提供，无需全局安装。`npm run dev` 启动只绑定本机的 API（4318）和网页（4173），工作台为 <http://127.0.0.1:4173>。如果服务已经运行，不要重复启动。网页版使用源码项目内的 `data/`，与桌面资料库相互独立。

首次启动载入约 30 秒云海示例工程。示例画面是内置 ImageGen 生成的素材，提示词与来源见 `public/demo/asset-prompts.md`；两段示例视频由该图生成推拉镜头，配乐为合成示例音频。重新生成示例需要 API 已运行：

```sh
npm run demo
```

- 每音轨M/S、全工程128音量关键帧（基础音量×相对倍率×淡化），支持精确dB、四种缓动、裁剪/分割/变速相位保持；立体声平衡、二阶高低通、无反馈单tap回声。实时Worklet、WAV和MP4使用同一个DSP数值实现；无桌面桥的浏览器模式不提供实时音频。
- 配乐与视频原声显示真实解码的源音频峰值波形，按裁剪、常规/分段/平滑曲线映射到时间线；显示按整份素材最大峰值固定归一，不表示音量、淡入淡出或音频效果后的响度。
- 画面缩放、位置、旋转、水平/垂直翻转、不透明度，亮度/对比度/饱和度调节；参数同时用于预览和合成。

桌面版和可选网页版共享编辑与媒体流程。尚未实现剪映完整组合动画、特效资源库、更多蒙版形状、智能抠像、自动语音识别、AI/云功能或剪映工程兼容。速度曲线使用独立的 source-domain smoothstep 函数，范围 0.25–4×；当前实时音频、导出与保调WAV使用整段连续Rubber Band R3/WindowShort源时钟及输出采样映射。0.7短块算法曾测得440→445.31Hz（+1.21%），保留为历史失败证据；后续版本分别使用预先冻结的稳态音高、标记、采样数和尾音标准验证，仍不承诺所有素材均达到完美保调或逐样本音画等价。1.0的实际实时输出与离线输出须以本轮有限夹具收据为准。速度曲线、调色、转场、动画和蒙版采用微剪明确记录的独立定义，不代表剪映专有算法或同名数值刻度。羽化预览与导出采用不同Gaussian栅格器，边缘允许采样差异。媒体格式能否在编辑器内预览取决于Electron/浏览器的解码能力；本地FFmpeg可处理更多导出输入格式。真实源波形不是混音后响度计。
