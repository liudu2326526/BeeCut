# BeeCut · 本地视频工作台

BeeCut 是一个在本机运行的视频编辑器，提供紧凑的深色三栏工作区、四条画面轨、四条音频轨和底部时间线。素材导入、剪辑、字幕、音频处理、工程保存和 MP4 导出使用真实的本地媒体引擎。项目独立于剪映和 REA，不包含剪映私有引擎或云服务。

仓库：[liudu2326526/BeeCut](https://github.com/liudu2326526/BeeCut)。当前源码版本为 **1.1.0**，项目原名“微剪”。本次统一源码中的产品名称、界面和打包配置；没有重新发布或安装 BeeCut 桌面包。历史发布报告继续使用当时的名称、文件路径和验收结果，不能作为本次改名后的原生 GUI 验收。

## 当前功能

- 本地导入视频、音频和图片，生成缩略图与真实解码的源音频波形。
- 四画面轨、四音频轨；素材拖放、横向及跨轨移动、裁剪、分割、吸附、碰撞检查、撤销和重做。
- 0.25–4× 常规倍速、分段恒速和连续平滑速度曲线；变换关键帧与音量关键帧。
- 缩放、位置、旋转、翻转、透明度、基础调色、圆形和矩形蒙版，18 种转场与 14 种入出动画。
- 文本字幕、描边、SRT 导入导出和中文字幕烧录。
- 音频分离、增益、淡入淡出、轨道静音/独听、声像、高低通和回声；桌面实时音频、离线保调 WAV 与 MP4 共用 DSP 定义。
- 工程自动保存、手动保存、保存后重开，以及 H.264/AAC MP4 的真实合成、进度和取消。
- 有限剪映草稿导入：原生选择文件夹、只读预检、时间线选择、逐项素材定位、差异确认、独立副本与完整映射报告。

剪映草稿导入当前只接受已通过固定公开结构和构造夹具验证的明文 `version=360000` 数据。**本机新版剪映 11.x 的不透明草稿仍不支持**；未知版本、无法映射的字段或超出容量的内容会明确报告。构造夹具不构成原生剪映往返兼容证据。详情见 [草稿兼容范围](JIANYING-DRAFT-COMPATIBILITY-REQUIREMENTS.md)。

自动语音识别、智能抠像、AI 生成、云协作、会员素材、完整特效资源库、任意动画组合以及完整剪映工程互通尚未实现。无桌面桥的浏览器模式不提供桌面实时音频。波形显示源素材峰值，不是混音后的响度计；媒体预览还受 Electron/浏览器解码能力限制。

## Mac 桌面版

桌面构建目前面向 **Apple Silicon、macOS 13+**，尚无 Intel 或 Windows 桌面包。应用内置 Electron、Node.js、FFmpeg、FFprobe 与音频 helper；正常使用时双击应用即可，无需另开媒体服务。启动时使用动态 loopback 端口，媒体处理在本机完成，关闭应用会等待本应用的媒体服务清理。

新构建的产品名为 `BeeCut.app`，本地打包输出为 `release/BeeCut.app` 和 `release/BeeCut-1.1.0-mac-arm64.zip`。这些是当前构建配置的输出名称，**仓库没有附带可下载的新桌面包**。已有的 `微剪.app` 和 `微剪-*.zip` 保留原名；其历史包身份和原生操作记录见 [1.1 历史发布验收](V11-RELEASE-VALIDATION.md)、[1.0 历史发布验收](V10-RELEASE-VALIDATION.md) 与各版本报告。

### 资料库与旧工程兼容

为继续识别已有应用和资料库，以下内部标识保留原值：

| 项目 | 当前值与行为 |
| --- | --- |
| 桌面应用身份 | `com.weijian.studio` |
| 桌面资料库 | `~/Library/Application Support/微剪/Library/`，保留现有位置 |
| 新导出文件的默认位置 | `~/Movies/BeeCut导出/`，保存对话框仍可选择其他目录 |
| 下载的工程文件 | 新文件使用 `.beecut.json`；既有 `.weijian.json` 仍可打开 |
| 工程数据格式 | 继续使用版本 `1`；更名不改变媒体 ID、DSP 或导入报告格式 |

资料库内的 `projects/` 保存工程，`media/` 保存导入素材副本，`exports/` 保存合成原件。应用包、桌面资料库与源码目录互相独立；更换应用包不需要移动资料库。工程 JSON 只引用媒体，不包含视频或音频本体，迁移和备份应保留整个 `Library/`。

“文件 → 显示本机资料库”和“文件 → 显示视频导出文件夹”可打开相应位置。旧的 `~/Movies/微剪导出/` 内容保留在原处。

旧网页版资料可通过“文件 → 导入旧网页版资料库…”选择完整 `data/` 文件夹。应用会先保存工程，再备份桌面资料库，复制并合并所选素材与工程；原文件夹保持不变。这个菜单用于 BeeCut 的旧网页版数据。剪映草稿使用单独的“文件 → 导入剪映草稿…”入口，并受上面的格式范围限制。

## 获取源码与开发

建议使用 Node.js **22.19+** 和 npm。FFmpeg/FFprobe 由 npm 依赖提供，不要求全局安装；Apple Silicon 桌面构建还需要 Xcode Command Line Tools 提供的 macOS SDK 与 C++ 编译器。

```sh
git clone https://github.com/liudu2326526/BeeCut.git
cd BeeCut
npm ci
npm run dev
```

开发工作台位于 [http://127.0.0.1:4173](http://127.0.0.1:4173)，本地 API 默认绑定 `127.0.0.1:4318`。开发网页版使用本目录的 `data/`，与桌面资料库独立；若服务已经运行，不要重复启动。仅静态部署页面不能提供本地媒体引擎。

新克隆不包含个人资料库或已生成的演示工程。需要云海示例时，保持开发服务运行，在另一个终端执行：

```sh
npm run demo
```

脚本使用仓库中的 AI 生成画面制作两段视频和合成配乐，将约 30 秒的演示工程保存到开发 `data/`。素材来源与提示词见 [演示素材说明](public/demo/asset-prompts.md)。开发 API 需先启动；不要将个人桌面资料库指定为演示生成目录。

### 检查与构建

```sh
# Apple Silicon Mac：先构建本地音频 helper
npm run audio-helper:build

# 先生成构建产物，再运行源码、API 与媒体回归；测试使用隔离数据
npm run build
npm run test:all
npm run test:sites
```

`npm run build` 生成 `dist/client/index.html`、`dist/server/index.js` 和 `dist/.openai/hosting.json`。它不会生成自带媒体引擎的桌面应用。

在 Apple Silicon Mac 上，先按上文生成演示工程，再停止开发服务并打包：

```sh
npm run desktop:package
npm run desktop:verify
```

打包只将明确选中的 `data/demo.json` 及其关联素材作为演示种子，不包含其他工程、个人导入素材或成片。它会生成暂存目录、ad-hoc 签名的应用、ZIP、SHA-256 文件及验证报告。构建、API、打包和签名检查应分别记录；通过这些检查本身不代表原生导入、拖放、保存重开或导出 GUI 已验收。

`data/`、`artifacts/`、`release/`、依赖、缓存、构建目录和本地密钥配置均通过 `.gitignore` 排除。历史文档中指向这些目录的证据链接只在保留相应本地文件时可用，不代表 GitHub 仓库已包含这些素材或安装包。

## 使用流程与范围

导入素材后，将素材卡片拖入目标轨道，移动或裁剪片段，在右侧修改画面、变速、音频和关键帧。在“文本”页添加字幕或导入 SRT，保存工程后点击“导出”，选择分辨率、帧率和画质，等待本地合成，再通过原生保存对话框另存 MP4。

当前资源界限包括：单文件 512 MB、每次导入最多 12 个文件；每工程最多 200 个素材、64 个片段、120 条字幕，最长 900 秒；变换关键帧、音量关键帧和曲线节点各最多 128 个。导出和保调 WAV 使用同一串行队列，最多排队 3 个任务。长时长、高分辨率或复杂效果的资源占用取决于素材；历史有限夹具的结果不构成所有设备与编码的保证。

完整操作见 [使用与能力清单](FEATURE-GUIDE.md)，字段和处理语义见 [编辑器合同](CONTRACT.md)，剪映参考观察与独立实现范围见 [功能对照](JIANYING-FEATURE-MAP.md)。历史原生 GUI 和媒体结果继续保留在各版本发布与验收文档中。

## 组件许可与本地使用

项目保留依赖各自的许可声明，包括 Electron/Chromium、React、Phosphor、FFmpeg/FFprobe 和固定版本的 Rubber Band 源码、许可证及构建元数据；桌面打包会将相关材料收集到 `Contents/Resources/licenses/`。仓库未声明一个可替代这些组件许可的统一发行许可。

当前桌面构建使用 ad-hoc 签名，未通过 Apple 公证。现有 FFmpeg 二进制的实际构建参数包含 `--enable-nonfree`，因此该打包方案仅供本机个人使用，不能作为对外分发版本。对外分发需要先替换媒体引擎构建并履行对应源码与许可义务。剪映的专有算法、会员能力和云资源不属于 BeeCut 的实现或授权范围。
